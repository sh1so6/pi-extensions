# @sh1so6/pi-fold-buttons

English | [日本語](README_ja.md)

[Pi](https://github.com/earendil-works/pi) extension. Adds "fold all / unfold all" buttons and a shared toolbar row that other extensions can use.

```bash
pi install npm:@sh1so6/pi-fold-buttons
```

- The search button of `@sh1so6/pi-path-click` is drawn in this row.
- See the header comment of [index.ts](index.ts) for configuration and commands.
