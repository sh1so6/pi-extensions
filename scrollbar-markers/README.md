# @sh1so6/pi-scrollbar-markers

English | [日本語](README_ja.md)

[Pi](https://github.com/earendil-works/pi) extension. Marks user messages (blue) and assistant replies (white) on the scrollbar.

```bash
pi install npm:@sh1so6/pi-scrollbar-markers
```

- See the header comment of [index.ts](index.ts) for configuration and commands.
